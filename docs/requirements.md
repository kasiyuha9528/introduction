# 自己紹介サイト 要件定義書

## 1. 概要

自分のプロフィール、できること、作ったもの、勉強中のことを紹介する個人サイト。
初めて訪れた人（採用担当者、仕事の依頼者、知人など）が、短時間で「どんな人か」「何ができるか」「どう連絡すればよいか」を把握できることを目的とする。

## 2. 想定閲覧者

| 閲覧者 | 知りたいこと |
|---|---|
| 採用担当者・企業 | スキル、制作実績、学習意欲 |
| 仕事の依頼者 | 対応できる領域、実績、連絡手段 |
| 知人・SNS経由の訪問者 | 人柄、最近の活動 |

## 3. サイト構成

1ページ構成（縦スクロール）とし、ヘッダーのナビゲーションから各セクションへページ内リンクで移動する。

```
/ （トップページ）
  ├─ ヒーロー（名前・肩書き・キャッチコピー）
  ├─ About（自己紹介）
  ├─ Skills（できること）
  ├─ Works（作ったもの）
  ├─ Learning（勉強中のもの）
  └─ Contact（連絡先）
```

- 将来的に制作物の詳細ページ（`/works/[slug]`）を追加できる構成にしておく。

## 5. デザイン

| 項目 | 内容 |
|---|---|
| トーン | ポップで明るく、親しみやすい雰囲気 |
| ベースカラー | オレンジ（例：`#FF8A1F`） |
| サブカラー | イエロー（例：`#FFC83D`）、アクセントにミント（例：`#3CC8A8`） |
| 背景色 | クリーム系の白（例：`#FFF8EE`） |
| 文字色 | 濃いブラウン（例：`#3A2414`）。真っ黒は使わずやわらかい印象にする |
| フォント | 丸ゴシック系（例：Zen Maru Gothic、M PLUS Rounded 1c） |
| 形状 | 角丸を大きくとったカード、太めの枠線、ずらした影（オフセットシャドウ） |
| 装飾 | 水玉・波線・吹き出しなどの図形、ホバー時に少し跳ねるようなアニメーション |
| ダークモード | 背景を濃いブラウン系にし、オレンジをアクセントとして残す |

- 文字と背景のコントラスト比を確保し、ポップさと読みやすさを両立する。

## 6. 機能要件

- ヘッダーナビゲーション（スクロール時も画面上部に固定）
- ページ内リンクによるスムーズスクロール
- スマートフォンではハンバーガーメニューに切り替え
- スクロールに合わせて各セクションをフェードイン表示
- ダークモード対応（OSの設定に追従）
- 外部リンクは新しいタブで開く

## 7. 非機能要件

| 項目 | 内容 |
|---|---|
| レスポンシブ | スマートフォン（幅375px〜）／タブレット／PCで崩れずに表示 |
| パフォーマンス | 静的生成（SSG）で配信し、Lighthouse の Performance 90点以上を目標 |
| SEO | ページタイトル・description・OGP画像を設定（Next.js の Metadata API を使用） |
| アクセシビリティ | 画像の alt、見出し構造、十分なコントラスト比を確保。アニメーションは `prefers-reduced-motion` で抑制 |
| 言語 | 日本語のみ |

## 8. コンテンツ管理

- 4章の掲載内容は、TypeScript のデータファイル（例：`src/data/profile.ts`）にまとめて管理する。
- 内容の更新はデータファイルを編集してデプロイする運用とし、CMS やデータベースは使用しない。
