# このプロジェクトで学んだこと

自己紹介サイト（Next.js + Tailwind CSS）を、AIアシスタント（Claude Code）と一緒に、要件整理から公開準備まで作る中で学んだことのまとめです。

## 1. 進め方：作る前に整理する

- 最初に「誰が見るのか」「何を知りたいのか」を決めてから作り始めた（`docs/requirements.md`）。
- 閲覧者（採用担当者、仕事の依頼者、知人）ごとに、載せる内容を考えた。
- 1ページ構成にし、ヘッダーから各セクションへページ内リンクで移動する形にした。
- 先に要件を決めておくと、作っている途中で迷いにくく、AIへの指示も具体的になる。

## 2. 技術の基本

| 技術 | 役割 | たとえ |
|---|---|---|
| Next.js | Webサイトを組み立てて配信する仕組み | 厨房 |
| React | 画面を「部品」の組み合わせで作る考え方 | 料理の材料 |
| Tailwind CSS | 色・余白・文字サイズなどの見た目の指定 | 盛り付けのルール |
| TypeScript | 間違いに気づきやすい JavaScript | レシピの誤字チェック |

## 3. リンクを開いてから画面に出るまで

1. ブラウザがサーバーに「ページをください」と依頼する。
2. サーバー（Next.js）が部品を集めて1ページに組み立てる。
3. 組み立てた結果（HTML・CSS・少しの JavaScript・フォント）がブラウザに届く。
4. ブラウザが画面に描く。スクロール時の動きなどは、届いたあとにブラウザ側で動く。

## 4. ファイル構成と役割

```
src/
├─ app/
│   ├─ layout.tsx      ページ全体の土台（題名・フォント）
│   ├─ page.tsx        ページの設計図（セクションを並べる順番）
│   └─ globals.css     共通の見た目
├─ components/         画面の部品（Header・Footer・各セクション）
│   └─ sections/       Hero / About / Career / Skills / Works / Learning / Contact
└─ data/
    └─ profile.ts      名前・経歴・連絡先などの中身（データ）
```

- **中身（データ）と見た目（部品）を分ける**と、内容の変更は `profile.ts` を書き換えるだけで済む。
- 同じ見た目は共通部品（`Section.tsx` など）にまとめると、直す場所が1か所で済む。
  - 実際に「セクションの外枠とカードのスタイルを共通化」の修正で体験した。

## 5. 表示速度の改善

- 日本語フォントはファイルが大きく、表示が遅くなる原因になる。
- サイトで実際に使う文字だけを残す「サブセット化」で軽くした（`scripts/subset-font.mjs`）。
- `npm run build` の前に自動でフォントを作り直す設定にした（`prebuild`）。
- `display: "swap"` により、フォントの読み込み中も文字は先に表示される。

## 6. 実際にやった改善の流れ

小さく作って、見て、直すを繰り返した。

1. サイトの土台を作る
2. 背景色を変える
3. ヒーロー画像をイラストに変更
4. 共通スタイルにまとめる
5. 経歴セクションを追加
6. フォントを軽量化
7. Works の見せ方を整理（サンプル発送依頼システムを外し、2列表示に）

## 7. Git（変更の記録）

- 変更は「何をしたか」が分かる単位で、日本語のメッセージ付きでコミットした。
- 不要なファイル（`.playwright-mcp/` など）は `.gitignore` に追加して、記録の対象から外した。

## 8. AIと作業するときのコツ

- 目的と条件を先に伝える（要件定義書がそのまま指示書になる）。
- 一度に全部ではなく、小さな変更ごとに確認する。
- Next.js は新しい版で仕様が変わっていることがある。`AGENTS.md` にもある通り、`node_modules/next/dist/docs/` の公式ドキュメントを確認してから書く。
- 分からない言葉は、たとえ話で説明してもらうと理解しやすい。

## 9. 動かし方

```bash
npm run dev     # 自分のPCで確認（http://localhost:3000）
npm run build   # 公開用に組み立てる
npm start       # 組み立てたものを動かす
```

## 10. 次に学びたいこと

- Vercel などでインターネットに公開する。
- 制作物の詳細ページ（`/works/[slug]`）を追加する。
- アクセシビリティ（読み上げ対応、色のコントラスト）を確認する。
